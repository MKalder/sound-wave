This project is a frontend practice exercise to improve my HTML, CSS, and JavaScript skills.

The concept is based on a business idea: a platform that connects music producers and musicians by sharing recording studios around the world.

Based on this idea, I started building the following website.

## Goal

The goal of this project is to practice frontend development while building a real-world inspired platform concept.

## Features

- Discover music studios around the world

- Connect producers with musicians

- Modern and responsive UI

- Lightweight and fast (no frameworks)

## 🛠 Tech Stack

- **HTML5** – Structure

- **CSS3** – Styling & layout (Flexbox / Grid)

- **JavaScript (ES6+)** – Interactivity
